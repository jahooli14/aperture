Not the loud kind

A two-firm match is the kind you'd catch eventually, given a reminder. These aren't that — each one only shows up if you're cross-checking vocabularies that have no reason to be compared.

A carrier, an MGA, a mutual, a broker and a fund each described the same hidden cost — and not one of them used the same words for it. No amount of remembering finds that. You'd have to be quietly holding five specialist vocabularies up against each other on the off-chance they matched.
